## 공통 원칙

### 세트 = 실험 ID

- 실험 ID 하나 = 1세트. 합성·측정·분석이 다른 레시피나 다른 랩에서 이루어지면 별도 세트로 두고 시료 ID로 잇는다.
    - 근거: 온톨로지 W3C PROV-O와 같은 기준(시료 = entity, 합성·측정 = activity)
- 태양전지 예: 레코드 1건(소자 제작 + JV) = PSC-EXP-20260213-007 1세트. 이 소자의 XRD를 분석 별도 랩에서 수행하면 추가 세트가 따로 생김.

### (X·Y) 구분은 모델의 역할

- 정방향 설계(조성·공정 → 물성)와 역설계(목표 물성 → 조성)는 x·y를 바꿔 씀
    - 근거: Sanchez-Lengeling & Aspuru-Guzik, Science 2018
- 자율실험실에서는 공정 실측값도 스스로 보정할 수 있음(예: 레시피 3 g → 실제 3.1 g → 토출 시간 조절). 그래서 "Y로 쓰이는 것"을 기준으로 세면 과제마다 숫자가 달라진다.
- 태양전지 예: "이 조성이면 PCE가 몇 %인가"(조성 = X)와 "PCE 25%를 내는 조성은 무엇인가"(조성 = Y)의 차이.
- 그래서 X·Y가 아니라 레시피와 측정·분석 결과로 나눠 센다(A).

## A. 레시피 1건 + 측정·분석 결과 (주 지표)

### 레시피는 1건

- 레시피 = 조성·구조·공정 조건 전체 + 측정 설정값 + 공정 기록 → 1건.
    - 공정 기록 = 레시피를 수행하며 남긴 실측값(칭량 질량, 압력·센서·장비 로그, 온도 프로파일). 소재를 잰 결과가 아니므로 레시피에 넣는다.
- 측정·분석 결과 = 레시피 단계 분류에서 측정 단계가 낸 결과(칭량 제외). 데이터팀이 1차 분류하고 랩이 확인한다.
    - 확인할 곳: 공정 단계에 붙은 분석 — CAM 펠릿 사진(성형), BAS GPC·회수율(정제·증발).
- 태양전지 예: 소자 제작 공정 파라미터 128자리와 JV 측정 설정(면적·스캔 방향)이 모두 레시피 1건.

### 측정·분석 결과는 각 1건, 파일도 1건

- 측정·분석 결과 = 측정 결과 하나. 파일과 그 파일에서 뽑은 숫자를 둘 다 센다. 파일마다 규칙을 두면 소재 분야마다 규칙을 계속 추가해야하고 추적관리가 불가능함.
- 랩이 '공정'으로 표기한 실측값(칭량 질량 등)은 레시피 1건에 들어간다.
- 태양전지 예: JV 측정 하나 = 곡선 파일 1 + PCE·Jsc·Voc·FF 4 = 5건. 스캔방향(정·역) 고려하면 10.

### 시편마다 1건, 같은 시편의 반복 측정은 2건

- 시편 = 측정 대상. 다른 시편은 각 1건. 같은 시편을 반복 측정하면 n과 무관하게 2건(값 + 불확도).
    - 반복측정을 하면 1회 측정과는 다른 측정결과와 불확도를 표현할 수 있음. n이 커지면 정밀도가 높아지지만 그 값의 개수는 늘어나지 않음. 100번을 재도 2건이라 부풀릴 수 없고, 반복 자체에는 1건을 더 줘 불확도를 확보하고, 좋은 성능만 보려는 편향을 줄이는데 도움이됨.(Hurlbert 1984, Ecological Monographs 54(2), 187–211)
- 같은 측정이라도 맥락이 다르면 별도(에이징 단계 뒤의 측정, 전지 사이클, 스캔 방향). 템플릿에서 측정·분석은 공정 순서에 지식그래프처럼 붙으므로 맥락이 구별된다. 같은 자리에 붙은 측정 여럿은 같은 조건.
    - 맥락은 단계로 기록돼야 셀 수 있다. 태양전지 registry에는 에이징 단계가 아직 없어 추가 후보.
- 태양전지 예: 같은 셀을 JV 10번 → PCE 2건. 셀 8개를 1번씩 → 8건(셀마다 개체로 등록됐을 때). 지금 ChemDX 데이터는 픽셀이 소자 개체 하나의 반복으로 들어가 있어 2건으로 센다 → 세트당 측정·분석 19.5건 + 레시피 1건 = A 20.5건(픽셀을 개체로 나누면 68.9). 시편 단위의 공통 원칙은 전 실험실 실데이터를 확인한 뒤 정한다.

## B. 설계인자 기준 (참고)

- B = 고정/변동 인자 묶음 1 + 설계인자 + 응답인자 = 1 + Σ설계인자 + Σ시편Σ항목 min(n, 2). 태양전지 6,695건(세트당 39.4), 설계인자를 조성/구조/공정 범주별로 묶으면 4,000건(23.5).
    - 응답인자 셈은 A의 측정·분석 셈과 같다. A와의 차이는 설계인자 항이다.
- 실험계획법(DoE)의 인자 분류를 따른다.
    - 응답인자(response factor) = 실험의 결과값(소재 물성/성능 측정-분석값) → 각 1건, 조성·구조·공정·물성/성능 범주로 분류.
    - 설계인자(design factor) = 실험에서 일부러 바꾸는 것 → 각 1건, 혹은 조성/구조/공정 범주별로 각 1건 최대 3건.
    - 고정 인자(held-constant) = 일부러 고정한 것 + 변동 인자(allowed-to-vary·nuisance) = 통제하지 않았는데 바뀐 것 → 묶어서 1건.
    - Montgomery, Design and Analysis of Experiments: 같은 변수는 제로 엔트로피로 학습 신호가 없음. 하지만 재현에 필요하므로 1로 셈(FAIR 원칙).
- 스케일업 관점의 예시: 태양전지의 면적, 촉매의 무게에 따라 물성이 바뀌고, 스케일업 관점에서는 해당 데이터는 주요한 설계인자.
- 랩이 선언한 환경 조건·장비 운용값·측정 설정은 묶음으로, 주요 변수(면적·질량 포함)는 설계인자로 둔다. 데이터팀이 1차 분류하고 랩이 확인한다.
- 태양전지 예: 공정 파라미터 자리 128개 중 106개는 같은 값(고정인자), 실험실 온도·습도·스캔 방향(변동 인자) → 묶음 1건. 나머지 값이 바뀐 설계인자는 19개(PVK 스핀 속도·시간, 용매와 양, HTL 도펀트, 표면처리 재료·농도, 측정 면적, 페로브스카이트 화학식 등) → 세트당 설계인자 18.9건.

## C. 지식그래프 트리플

- 1건 = 지식그래프 트리플 하나(주어–관계–목적어). 5시트 데이터를 플랫폼 적재기로 그래프로 만들어 센다.
- 온톨로지 기반 사업 취지와 맞고 기계적으로 재현된다. 다만 모델링 방식·적재기 판에 따라 숫자가 바뀌므로 판을 고정해 보고한다.
- 태양전지 예: 170세트 = 340,431 트리플(세트당 2,003). 측정값 하나가 트리플 약 14개.
