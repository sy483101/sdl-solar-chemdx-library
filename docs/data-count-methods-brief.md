# 데이터 건수 셈법 — 세 가지 안

> 전략연구사업 소재데이터 정량지표 · 데이터팀 초안 2026-10-15 · 대상: 연구책임자·참여연구원.
> 논의 기록 = `docs/intent/data-count-methods.md` · 계산 = `scripts/count_methods.py` → `reports/count-methods-dev-20261014b.md`.

## 요약

- 계획서는 2026년 455세트·5,900건(5년 10만 건)이다. 지금 입력 화면의 셈법(채워진 칸 = 1건)으로 세면 태양전지 한 세트가 **167건** —
  계획서 태양전지 세트당 **11건**의 15배다. 공정 칸의 57%는 registry 기본값이다.
- 칸이 아니라 **정보의 단위**로 세는 세 가지 안을 제안한다. 보고 숫자는 1차 실데이터 수집 뒤 셋 중에서(또는 병기해) 고른다.

| 안 | 1건 = | 산식 | 태양전지 2026 (170세트) | 세트당 |
|---|---|---|---:|---:|
| **A** | 지식그래프 트리플 하나 | 트리플 수 | 340,431 | 2,003 |
| **B** | 설계인자 하나 · 응답 하나 (고정·변동 인자는 묶어 1) | 1 + Σ설계인자 + Σ<sub>시편</sub>Σ<sub>항목</sub> min(n, 2) | 6,695 | 39.4 |
| **C** | 조건 전체 1 · 측정 항목 하나 | 1 + 측정 항목 수 | 1,850 | 10.9 |
| 참고 | 채워진 칸 하나 (현행) | | 28,398 | 167 |
| 계획서 | | | 300세트 · 3,300 | 11.0 |

태양전지 = ChemDX 의 KRICT 2026년 등록분을 5시트 라이브러리로 바꾼 것(PSC-RCP-03 n-i-p 소자 + JV 측정).

## 1. 세트 = 실험 ID

- 실험 ID 하나 = 1세트. 합성·측정·분석이 다른 레시피나 다른 랩에서 이루어지면 **별도 세트**로 두고 시료 ID 로 잇는다.
  레시피 하나를 끝까지 수행한 기록이 1세트다.
- 근거: ISA 체계는 시료 준비(Study)와 측정(Assay)을 따로 기록하고 시료로 연결한다. W3C PROV-O 도 같다(시료 = entity, 합성·측정 = activity).
- **태양전지 예**: ChemDX 레코드 1건(소자 제작 + JV) = `PSC-EXP-20260213-007` 1세트. 이 소자의 XRD 를 분석 지원 랩이 재면 그 랩의 세트가 따로 생기고 소자 ID 로 이어진다.

## 2. X·Y 는 데이터의 성질이 아니라 모델 안의 역할

- 정방향 모델(조성·공정 → 물성)과 역설계(목표 물성 → 조성)는 **같은 기록에서 x·y 를 바꿔 쓴다**. 공정 실측값도 자율실험실이 장비를 스스로
  보정하면(레시피 3 g → 실제 3.1 g → 토출 시간 조절) 타겟이 된다. 그래서 "Y 로 쓰이는 것"을 기준으로 세면 과제마다 숫자가 달라진다.
- 근거: Sanchez-Lengeling & Aspuru-Guzik, *Science* 2018 · Zunger, *Nat. Rev. Chem.* 2018.
- **태양전지 예**: "이 조성이면 PCE 가 몇 %인가"(조성 = X)와 "PCE 25% 를 내는 조성은 무엇인가"(조성 = Y)를 같은 170세트로 학습한다.
- → 역할 대신 **실험마다 값을 일부러 바꾸는가**로 나눈다(3절).

## 3. 설계인자는 각 1건, 고정·변동 인자는 묶어 1건

- 실험계획법(DoE)의 인자 분류를 따른다.
  - **설계인자**(design factor) = 일부러 바꾸는 것 → 각 1건, 조성·구조·공정 범주별로.
  - **고정 인자**(held-constant) = 일부러 고정한 것 + **변동 인자**(allowed-to-vary·nuisance) = 통제하지 않았는데 바뀐 것 → 묶어서 1건.
- 판정 = 랩이 선언한 것 ∪ 실데이터에서 세트마다 값이 달라진 것. 환경 조건·장비 운용값·측정 설정은 묶음으로, **규모(면적·질량)는 설계인자**로.
  데이터팀이 1차 분류하고 랩이 확인한다.
- 근거: Montgomery, *Design and Analysis of Experiments*. 값이 늘 같은 변수는 엔트로피가 0 이라 학습 신호가 없다 — 그래도 랩을 합치면 달라지고
  재현에 꼭 필요하므로 0 이 아니라 1 로 센다(FAIR R1). 규모: 태양전지 효율은 면적이 커지면 떨어져 공인 효율표도 면적 구간별로 따로 싣고,
  촉매 1 g 과 1 kg 은 열·물질전달과 공간속도가 달라 같은 상관을 갖지 않는다.
- **태양전지 예**: 공정 파라미터 자리 128개 중 106개는 170세트 내내 값이 하나다(registry 기본값 포함) → 묶음 1건.
  값이 바뀐 22자리 중 실험실 온도·습도·스캔 방향은 묶음, 나머지 19자리(PVK 스핀 속도·시간, 용매와 양, HTL 도펀트, 표면처리 재료·농도, 측정 면적 등)와
  페로브스카이트 화학식이 설계인자 → **세트당 설계인자 18.9건**.

## 4. 응답(물성·성능)은 각 1건 — 파일도 1건

- 응답 = 측정 결과 하나. 숫자와 파일을 가리지 않고, **파일과 그 파일에서 뽑은 숫자를 둘 다** 센다(파일마다 규칙을 두면 끝이 없고,
  파일 하나에서 응답이 여럿 나올 수 있으니 보수적인 셈이다). XRD 같은 물성도 성능과 같은 응답이다.
- 랩이 '공정'으로 표기한 실측값(칭량 질량 등)은 묶음에 넣는다. 랩이 보정 타겟으로 쓰겠다고 하면 응답으로 센다.
- **태양전지 예**: JV 측정 하나 = 곡선 파일 1 + PCE·Jsc·Voc·FF 4 = 응답 5. 정·역방향이면 10.

## 5. 시편마다 1건, 같은 시편의 반복 측정은 2건

- 시편 = 측정 대상 개체. 다른 시편은 각 1건. 같은 시편을 반복 측정하면 **n 과 무관하게 2건**(값 + 불확도).
  같은 시편이라도 다른 시점·조건에서 잰 것(숙성 일수, 전지 사이클, 스캔 방향)은 반복이 아니라 다른 항목이다.
- 근거:
  - 측정 결과는 측정값과 측정 불확도로 표현한다(VIM 2.9). 반복이 있어야 A형 불확도(s/√n, GUM 4.2.3)가 나온다.
  - 반복값이 정규분포면 n 개가 가진 정보는 평균과 분산 둘에 다 담긴다(충분통계량) — n 이 커지면 두 값이 정밀해질 뿐 개수는 2 다.
  - 조건 ⊃ 시편 ⊃ 측정의 계층 설계: 독립 시편의 정보는 더해지고(각 1), 시편 안 반복은 그 시편의 평균·분산(2)이다.
    같은 시편 반복은 서로 상관돼 아무리 늘려도 정보가 크게 늘지 않는다(Hurlbert 1984 유사반복 · Kish 1965).
  - 100번을 재도 2건이라 부풀릴 수 없고, 반복 자체에는 1건을 더 줘 불확도 데이터를 내놓을 동기가 생긴다.
    잘 나온 소자만 보고하는 편향을 줄이는 데도 도움이 된다(Christians et al., *JPCL* 2015).
- **태양전지 예**: 같은 셀을 JV 10번 → PCE 2건. 셀 8개를 1번씩 → 8건(셀마다 개체로 등록됐을 때).
  지금 ChemDX 데이터는 픽셀이 소자 개체 하나의 반복으로 들어가 있어 2건으로 센다 → 세트당 응답 **19.5건**(픽셀을 개체로 나누면 67.9).
  시편 단위의 공통 원칙은 전 실험실 실데이터를 확인한 뒤 정한다.

## 6. 세 안 비교

| 안 | 장점 | 한계 |
|---|---|---|
| A 트리플 | 기계적으로 세고 재현된다 · 온톨로지 기반 사업 취지와 맞다 | 데이터보다 모델링 방식에 좌우된다(값 하나 ≈ 14 트리플) · 온톨로지·적재기 판이 바뀌면 숫자가 변해 판을 고정해야 한다 → 상한 지표 |
| B | 계획서처럼 조성·구조·공정·분석 칸을 채운다 · 과제와 무관하다 · 반복에 크레딧 | 설계인자 판정에 랩 확인이 필요하다 |
| C | 가장 단순하고 보수적이다 · 태양전지에서 계획서와 같다(10.9 vs 11.0) | 범주별 칸을 채우지 못한다 · 설계인자·반복 차이가 드러나지 않는다 |

세 안은 A ≥ B ≥ C 순의 상한·중간·하한이다.

## 7. 남은 것

- 기본값(확인 중): 2건 문턱 = n≥2(화학 관례 3회 반복에 맞춘 n≥3 도 가능 — 95% 신뢰구간 t 값 12.7 vs 4.3) · B 의 묶음 1건은 계획서 4칸 중 공정 칸 ·
  C 의 '1' 에는 조성·구조·공정이 모두 들어간다.
- 시편 단위 공통 원칙(태양전지 픽셀 등) — 전 실험실 실데이터 확인 뒤.
- 랩 확인: 설계인자 목록 · 공정 실측값을 보정 타겟으로 쓰는지(예: 석유화학촉매 칭량 질량).
- ChemDX 10세트(KRICT-SC-03572~03586)는 곡선 파일명에 숙성 일수(1day·2day)와 다른 조건으로 보이는 숫자가 섞여 있어 랩 확인이 필요하다.
