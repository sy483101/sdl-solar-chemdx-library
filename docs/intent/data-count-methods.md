# 데이터 건수 셈법 — 칸 단위 vs 타겟(Y) 단위 (2026-10-14 논의 · 정의 확정)

> 상태: 셈법 정의 확정(사용자 10-14) → **10-15 재논의 중** — 끝의 "재논의" 절이 새 기준 초안(확정되면 정의 표를 바꾼다).
> 보고·평가에 어느 셈법을 쓸지는 **보류** — 1차 실데이터 수집 뒤 고른다.
> 설득 문서(재논의 반영, 안건마다 태양전지 예시) = `docs/data-count-methods-brief.md`.
> 계산 = `scripts/count_methods.py`(ChemDX 실데이터 + 트리플) · `scripts/lab_estimate.py`(랩별 registry 레시피 추산).
> 숫자 = `reports/count-methods-<빌드>.md` · `reports/lab-estimate-registry-v<판>.md`.

## 배경

- 전략연구사업은 5개 분야 소재 실험 데이터를 온톨로지 기반으로 모은다. 계획서는 **실험 한 건 = 한 세트**로 보고,
  세트마다 조성·구조·공정·분석 건수를 추산해 더해 **5년 10만 건**으로 잡았다(2026 = 455세트 · 5,900건).
- 지금 sdl-prefill `sheets.data_counts`(웹 화면·정량지표 공용)는 **채워진 칸 하나 = 1건**이다(registry 기본값 포함).
- 10-14 주변 연구자 토의의 반론: 한 실험에서 바뀌는 변수는 한두 개뿐인 경우가 많은데, 그대로인 공정 변수·CAS·화학식까지 칸마다 1건으로
  세는 것이 맞나? → AI 모델링의 **타겟(Y)만 따로 세고**, 거기까지 거친 **피처(X)는 묶어서** 세야 한다는 논리.
- 두 논리 모두 근거가 있어 **둘 다 추산해 두고** 나중에 고르기로 했다.

## 정의(확정)

| 셈법 | 정의 |
|---|---|
| **A** 칸 단위 | 채워진 칸 = 1건(조성 = 개체 정보 칸 · 공정 = 파라미터 + 투입량 · 분석 = 측정값·파일). 현행 `data_counts` 그대로 |
| A′ | A 에서 registry 기본값(Source=default) 칸을 뺌 = 연구자가 적은 칸만 |
| **B** 범주 + Y(반복마다) | 조성 1 + 구조 1 + 공정 1(있을 때) + **Y 를 반복 측정 횟수만큼** |
| **C** X 1 + Y(항목마다) | X 1 + **Y 를 측정 항목(스텝·결과 이름)마다 1** — 반복은 묶음 |
| (참고) ML 표본 행 | Y 를 낸 측정(스텝·반복) 하나 = 1 — 학습 데이터의 행 수 |

**Y** = Value 시트의 **측정 결과 행 하나 = 1건**.
- 숫자·파일 가리지 않는다 — **파일 하나 = Y 1건**. 측정 비정형 데이터 하나에서 Y 가 여러 개 나올 수 있으니 보수적 셈이다.
- **파일과 그 파일에서 뽑은 숫자는 둘 다 센다**(JV 곡선 1 + PCE·Jsc·Voc·FF 4 = 5). 파일마다 따로 규칙을 두면 끝이 없다.
- XRD 결정크기·상분율 같은 **물성도 성능과 같은 Y**. 전환율·수율·쿨롱효율도 Y(물성·성능).
- **예외 하나**: 랩이 registry Kind 에 **공정(Process)** 이라고 적은 결과 = 공정 중 실측값(칭량 질량 · 압력·온도 로그 등) → **X**.
  기준은 랩 표기 — MPSP 매핑이 바꾼 Kind 가 아니다(BAS 전환율·수율은 MPSP 로는 process 지만 랩 표기 Performance → Y).

**X 범주(B)**
- 조성 = 개체 정보 칸이 있으면 1 · 공정 = 파라미터·투입량이 있으면 1.
- **구조 = 구성(structure/configuration)** — 부분들이 어떻게 짜였는가(적층 순서 · 소자 형식 · 셀 형식).
  **산출물이 부품·소자(플랫폼 J2 판정 component·device)면 1**, 분말·용액 같은 재료면 0. 랩마다 손으로 정하지 않는다.
  측정으로 얻은 구조값(XRD 등)은 Y.

## 재논의(10-15, 진행 중)

**목적**: 1차 실데이터 수집 전에 건수 셈법 셋(A·B·C)을 산출 조건·과학적 근거·산식과 함께 짧은 문서로 → 연구책임자·참여연구원 설득.
보고 수치는 1차 수집 뒤 고른다.

**합의한 것**
- **세트 = 실험 ID**. 합성·측정·분석이 다른 레시피·랩이면 별도 세트, 시료 ID 로 잇는다(ISA Study–Assay, Sansone et al., *Nat. Genet.* 2012 ·
  W3C PROV-O · prefill `Source=import`). 레시피 하나를 끝까지 수행한 기록 = 1세트.
- **X·Y 는 데이터의 성질이 아니라 모델 안의 역할** — 정방향(조성·공정 → 물성)과 역설계(목표 물성 → 조성)에서 같은 기록의 x·y 가 서로 바뀐다
  (Sanchez-Lengeling & Aspuru-Guzik, *Science* 2018 · Zunger, *Nat. Rev. Chem.* 2018). 공정 실측값도 SDL 이 공정을 스스로 보정하면 Y 가 된다
  (예: 레시피 3 g → 실제 평균 3.1 g → 토출 시간·문턱값을 조절해 3 g 에 맞춤 = 칭량 질량이 타겟). → 'Y 로 쓰이는 것'으로 세면 과제마다 숫자가 달라진다
  → 역할 대신 **실험마다 값을 일부러 바꾸는가**로 나눈다.
- **용어(DoE, Montgomery *Design and Analysis of Experiments*)**: **설계인자(design factor)** = 일부러 바꾸는 것 ·
  **고정·변동 인자** = 일부러 고정한 것(held-constant) + 통제하지 않았는데 바뀌는 것(allowed-to-vary·nuisance, 예: 실험실 온습도).
- **설계인자 판정** = 랩 선언 ∪ 실데이터 관측 변동. 관측 변동 중 변동 인자는 판별해 묶음으로 보낸다. registry Variable 표시는 지금 랩마다 뜻이 달라
  (PCC·PSC 0 · ELF 43/48 · CAM 45/48 — sampleId 같은 운용값 포함) 그대로는 못 쓴다.
  **판별 = 데이터팀 규칙으로 1차 분류 → 랩 최종 확인**: 환경 조건(실험실 온습도) · 장비 운용값(sampleId·slotId·pumpId) · 측정 설정(스캔 방향) → 묶음 ·
  나머지 관측 변동 → 설계인자 후보. **규모(면적·질량)는 설계인자** — 스케일업은 산업화의 핵심이고 규모에 따라 상관관계가 달라진다
  (태양전지 효율은 면적이 커지면 투명전극 저항·막 균일도 탓에 떨어져 공인 효율표도 면적 구간별로 따로 싣는다 · 촉매 1 g 과 1 kg 은
  열·물질전달과 공간속도(WHSV = 공급량/촉매 질량)가 달라 같은 상관을 갖지 않는다).
  ChemDX 2026 관측 변동 22자리 → 묶음 3(실험실 온도·습도 · JV 스캔 방향) · 설계인자 후보 19(JV activeArea 포함).
- **B 초안** = 고정·변동 인자 통합 1 + 설계인자 각 1(조성·구조·공정 범주별 — 범주 = MPSP 경로) + 물성·성능(응답) 각 1.
  묶음을 0 이 아니라 1 로 세는 근거: 한 랩 안 상수는 엔트로피 0(학습 신호 없음)이지만 랩을 합치면 달라지고 재현에 필요하다(FAIR R1, Wilkinson et al., *Sci. Data* 2016).
- 새 A·C 초안: A = 트리플 수(상한 · 온톨로지·적재기 판 고정) · C = X 전체 1 + 물성·성능 수.

**반복 규칙(사용자 10-15)** = **시편마다 1건 · 같은 시편의 반복 측정은 n 과 무관하게 2건**(값 + 불확도).
- 근거: 측정 결과 = 측정값 + 측정 불확도(VIM JCGM 200:2012 2.9) · 정규 반복이면 n 개의 정보가 평균·분산 둘에 다 담긴다(충분통계량) ·
  100번 재도 2건이라 부풀리기 비판이 없다 · 반복했다는 데 최소 크레딧.
- 계층(nested) 설계와 같은 꼴: 조건 ⊃ 시편 ⊃ 측정. 시편 간 분산(공정 재현성) + 시편 안 분산(측정 반복성) — 독립 시편은 정보가 더해지니 각 1,
  시편 안 반복은 그 시편의 (평균, 분산) = 2. 시편 = 실험 단위(experimental unit), 같은 시편 반복 = 부표본(Hurlbert 1984).
- 반복이 아닌 것: 같은 시편을 **다른 시점·조건**에서 잰 것(숙성 일수·전지 사이클 번호·정/역방향) = 다른 측정 항목.
- **시편 = 분석·측정에 쓴 개체**(Value.TargetEntityID, 사용자 10-15) — 분야마다 시편 원칙을 따로 세우지 않는다. 랩이 등록한 개체가 곧 시편 단위.
  온톨로지 근거: 측정(assay)의 대상 개체 = 시편(OBI evaluant role · PROV `used`). 따로 등록하지 않은 시편은 한 개체로 묶여 2 — 적게 세는 쪽이 기본값.
- 태양전지 픽셀: 소자(device) 개체에 다중 픽셀 개념이 없어 픽셀이 RepeatNo 로 들어간 것 → 지금 규칙이면 독립 픽셀 10개도 2건(과소 셈).
  엔진은 측정 스텝 하나에 대상 개체 여러 개를 이미 받는다(값마다 `target`) — 픽셀 = 소자 개체로 넣으면 풀린다. 그러나
  **모든 실험실 실데이터를 확인하고 공통 원칙을 세우면서 고친다(사용자 10-15) — 지금은 개체 기준 그대로(ChemDX 세트당 Y 19.5)**. 변환기는 고치지 않는다.
- ChemDX 2026 Y(세트당): **개체 = 시편(지금 규칙) 19.5** · (참고: 픽셀이 개체가 되면 67.9 · 기판이면 37.6) · C 9.9 · 계획 10.0.
- ChemDX 2026 **B 초안 = 6,695(세트당 39.4)** = 묶음 1 + 설계인자 18.9(페로브스카이트 화학식 1 · 파라미터 19자리 중 채워진 것 17.9) + 응답 19.5.
  범주(조성·구조·공정) 나눔은 MPSP 경로로 — 스크립트 반영 때.
- 발견(랩 확인): 10세트(KRICT-SC-03572~03586)는 곡선 파일명에 `1day`·`2day` 와 조건으로 보이는 숫자(1.6~2.4)가 섞여 있다 —
  같은 픽셀 두 번(16건)은 숙성 일수가 다른 측정(반복 아님), 한 레코드에 여러 조건이 섞였을 수도(D7 레코드 = 세트).

**반복 — 근거**
- 평균의 표준불확도 = s/√n(GUM JCGM 100:2008 4.2.3, A형 평가) — 반복이 없으면 오차 막대가 없다. 반복 = Fisher(1935) 실험설계 3원칙의 하나.
- 독립 반복이면 Fisher 정보가 n 에 비례해 더해진다(= 표준오차가 1/√n 으로 준다, Cramér–Rao). 같은 시편 반복처럼 상관 ρ 가 있으면
  평균의 분산 = σ²/n·(1+(n−1)ρ) → n 을 늘려도 σ²ρ 아래로 안 준다(유효 표본 수 n/(1+(n−1)ρ), Kish 1965).
- → 다른 시편(소자·픽셀·배치) 반복은 독립 표본, 같은 시편 반복 측정은 정보가 덜 는다(Hurlbert, *Ecol. Monogr.* 1984 유사반복).
  ChemDX '반복' = 기판 2 × 픽셀 4(다른 소자) — 지금 템플릿은 둘 다 RepeatNo.
- 크레딧: 모든 기록을 세면 나쁜 셀까지 올라와 분포 편향이 준다(Christians, Manser & Kamat, *JPCL* 2015 · 실패 실험의 가치 Raccuglia et al., *Nature* 2016).

**열린 것(재논의)**: 2건 문턱(n≥2 vs n≥3) · 묶음 1건을 계획서 4칸 중 어디에 · C 의 '1'에 조성 포함 여부.
